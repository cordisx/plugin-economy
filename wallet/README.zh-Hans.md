# Token 钱包插件

展示原本地钱包的可用与冻结余额、用量收入、流水与购买凭证。实际分类 Codex Host 用量继续通过原收入流程，当前页面与共享金币视觉保持既有版本。

Pet 使用 Wallet 发布的 `economyWalletCommerce` 服务。Wallet 通过公开 `ctx.walletSpend` 调用 Host 的固定原生确认和私有授权，不传调用方身份、签名权限或任意桥接。订单与明确取消互斥持久化；断线、未知结果和钱包代际变化继续保留原待确认请求。只读维护阻止写操作。

当前合同见[本地消费](../docs/local-spend.md)，完整开发命令、正常 SDK 安装与验证范围见[英文说明](README.md)。自动测试通过不等于实际 Host 已接入、原生验收、合并或部署。
