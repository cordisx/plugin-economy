# CordisX 共享娱乐 Token

可自托管的持久账本、类型化客户端与 CordisX 钱包。账户按经济实例隔离，
所有余额为整数。用户明确确认游戏版本、审核状态、席位投入与固定结算政策后冻结；
服务只能按已授权政策守恒结算。未经审核的游戏可以使用 Token。

没有真钱、提现或公开发币接口。收入来自运营者明确授权的有限来源；本地 usage
不视为可信云账单。Pet 使用持久订单和一次性受控迁移凭证。

运行 `npm ci && npm run check`。参阅[部署](docs/deployment.md)、
[API](docs/economy-api.md)与[钱包](wallet/README.zh-Hans.md)。
目前为实验性实现，自动测试、原生验证、部署和用户验收分别报告。
