# CordisX 共享娱乐 Token

持久的原本地钱包账本、类型化客户端与 CordisX 钱包。Token 新收入只来自实际分类后的 Codex Host 模型用量；保留原账户、用量范围、流水与历史凭证。

游戏明确披露服务、规则版本与摘要、审核状态和每位用户投入。结算最多消耗同一用户冻结的本金，并退回其余本金；游戏胜负使用分数或筹码，不产生 Token 收入或跨钱包奖励。未经审核的游戏仍可在明确的原生确认后使用此流程。

Pet 通过 `economyWalletCommerce` 购买，订单与明确取消共用同一持久请求记录。未知结果继续保留待确认。历史奖励、迁移与普通 bearer 金融写入口已停用；完全匹配的既有已提交凭证仍可读取。

运行 `npm ci && npm run check`。参阅[当前本地消费合同](docs/local-spend.md)、[配置与恢复](docs/deployment.md)、[历史 API](docs/economy-api.md)与[钱包](wallet/README.zh-Hans.md)。自动测试、实际运行接入、原生验证、部署和用户验收分别报告。
